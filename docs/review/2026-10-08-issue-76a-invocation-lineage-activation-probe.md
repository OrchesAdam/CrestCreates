## 1. Production Paths Under Test

### Agent Tool Invocation Path
```
Agent Runtime
  → AgentExecutionContext (ExecutionId, InvocationId, CausationId?)
  → IAgentToolInvoker.InvokeAsync(request)
  → ICapabilityDispatcher.DispatchAsync(capability, InvocationSource.Agent, input, configureContext)
  → Capability Pipeline
  → AuditMiddleware
  → AuditEnvelope (durable evidence)
```

### Evidence Structure
Each Agent Tool invocation produces one `AuditEnvelope` containing:
- `AuditId`: Unique capability-level execution identifier
- `CorrelationId`: Links related operations in a logical chain
- `CausationId`: Parent invocation identifier (from AgentExecutionContext.CausationId)
- `ParentAuditId`: Enclosing audit scope (if any)
- `Runtime.References`: 
  - `("agent-session", ExecutionId)` — groups invocations in same agent execution
  - `("agent-invocation", InvocationId)` — identifies current invocation
- `Actor`: Agent identity (`Kind="agent"`, `Id=AgentId`)
- `Runtime.InvocationSource`: `"Agent"` — indicates origin

## 4. Post-Hoc Reconstruction Algorithm

### Input
- `IReadOnlyList<AuditEnvelope> envelopes` — durable evidence from one or more executions

### Output
- `Dictionary<string, (string? Parent, List<string> Children)>` — reconstructed invocation tree

### Algorithm
```csharp
1. Initialize tree nodes:
   foreach envelope in envelopes:
     invocationId = envelope.Runtime.References.Single(r => r.Kind == "agent-invocation").Id
     parentId = envelope.CausationId
     tree[invocationId] = (Parent: parentId, Children: [])

2. Build parent-child relationships:
   foreach envelope in envelopes:
     invocationId = GetInvocationId(envelope)
     parentId = envelope.CausationId
     if parentId is not null and tree.ContainsKey(parentId):
       tree[parentId].Children.Add(invocationId)

3. Return tree
```

### Reconstruction Capabilities
- **Root identification**: `CausationId == null`
- **Direct parent**: `CausationId` value
- **Siblings**: Same `CausationId`
- **Multi-level path**: Follow `CausationId` chain
- **Execution boundary**: `agent-session` reference
