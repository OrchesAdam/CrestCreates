# Phase 7c Follow-up: Agent Draft Payload Contract Source Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate the Agent-editable metadata contract for descriptor draft payloads via a Roslyn source generator, replacing the current hand-written DTOs, projections, and merge helpers.

**Architecture:** A new `CrestCreates.Agent.DraftContracts` project hosts the contract spec source files and receives generated output. A new `AgentDraftContractGenerator` under `CrestCreates.CodeGenerator` reads spec files via `AdditionalFiles`, classifies descriptor properties, and generates DTOs, patch DTOs, changed-field enums, projection helpers, merge helpers, manifest, and validation helpers. The existing `Agent.ControlPlane.Abstractions` and `Agent.ControlPlane` projects migrate from hand-written to generated types.

**Tech Stack:** .NET 10, Roslyn IIncrementalGenerator (netstandard2.0), System.Text.Json source generation, xUnit + FluentAssertions for tests

## Global Constraints

- Generator targets `netstandard2.0` with `EnforceExtendedAnalyzerRules=true`
- Generated code must be AOT-friendly: no runtime reflection, no `dynamic`, no `JsonElement`, no `object` escape hatches
- `DescriptorRef` from `CrestCreates.Metadata.Abstractions` is reused directly; do not generate a duplicate
- `AgentVersionedDescriptorRefDto` is generated only when `DescriptorRef` cannot losslessly represent the domain shape (it lacks `SelectionMode` and `ExpectedContractHash`)
- `Preserve` fields are never emitted into DTOs, never adapter-editable, and never represented as opaque subtrees
- `Create` uses `AgentDraftPayloadDto` (no `ChangedFields`); `Merge` uses `AgentDraftPayloadPatchDto` (with `ChangedFields`)
- Compiler diagnostics `ADP001`–`ADP010` are separate from runtime codes `ADPC001`–`ADPC012`; never place both in one enum
- JSON context is NOT generated by this generator; `AgentControlPlaneToolJsonSerializerContext` registers generated types downstream
- No hand-written fallback for Agent draft payload contract may remain in the active build after migration
- Tests do not rely on hardcoded descriptor kind count
- The spec document at `docs/superpowers/specs/2026-06-21-phase-7c-agent-draft-payload-contract-source-generator-design.md` is the authoritative reference; this plan is derived from it

```csharp
namespace CrestCreates.Agent.DraftContracts.Dto;

public sealed record AgentDraftContractResult<T> where T : class
{
    public bool IsSuccess { get; init; }
    public T? Value { get; init; }
    public IReadOnlyList<AgentDraftContractError> Errors { get; init; } = [];

    public static AgentDraftContractResult<T> Success(T value) => new() { IsSuccess = true, Value = value };
    public static AgentDraftContractResult<T> Failure(IReadOnlyList<AgentDraftContractError> errors) => new() { IsSuccess = false, Errors = errors };
    public static AgentDraftContractResult<T> Failure(AgentDraftContractError error) => Failure([error]);
}
```

```csharp
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.CSharp.Syntax;
using Microsoft.CodeAnalysis.Text;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace CrestCreates.CodeGenerator.AgentDraftContractGenerator;

[Generator]
public sealed class AgentDraftContractSourceGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        // Find all classes with [AgentDraftContractSpec] attribute
        var specClasses = context.SyntaxProvider
            .CreateSyntaxProvider(
                predicate: static (node, _) => node is ClassDeclarationSyntax,
                transform: static (ctx, _) => GetSpecClassInfo(ctx))
            .Where(static spec => spec is not null);

        var specsAndCompilation = specClasses.Collect().Combine(context.CompilationProvider);

        context.RegisterSourceOutput(specsAndCompilation, static (sourceContext, pair) =>
        {
            var (specs, compilation) = pair;
            GenerateContractCode(sourceContext, compilation, specs!);
        });
    }

    private static SpecClassInfo? GetSpecClassInfo(GeneratorSyntaxContext context)
    {
        var classDecl = (ClassDeclarationSyntax)context.Node;
        var symbol = context.SemanticModel.GetDeclaredSymbol(classDecl) as INamedTypeSymbol;
        if (symbol is null) return null;

        // Check for [AgentDraftContractSpec] attribute
        var specAttr = symbol.GetAttributes().FirstOrDefault(a =>
            a.AttributeClass?.ToDisplayString() == "CrestCreates.Agent.DraftContracts.Specs.AgentDraftContractSpecAttribute");

        if (specAttr is null) return null;

        // Extract Kind from attribute
        var kindArg = specAttr.NamedArguments.FirstOrDefault(kvp => kvp.Key == "Kind");
        if (kindArg.Value.Kind == TypedConstantKind.Error) return null;

        var kindName = kindArg.Value.Value?.ToString() ?? "Unknown";

        return new SpecClassInfo(symbol, kindName);
    }

    private static void GenerateContractCode(SourceProductionContext context, Compilation compilation, System.Collections.Immutable.ImmutableArray<SpecClassInfo> specs)
    {
        var modelBuilder = new ContractModelBuilder(compilation, context);
        var model = modelBuilder.Build(specs);

        if (model is null || model.Kinds.Count == 0) return;

        // Check for diagnostics
        if (context.CancellationToken.IsCancellationRequested) return;

        // Generate DTOs
        var dtoWriter = new AgentDraftContractDtoWriter();
        context.AddSource("AgentDraftPayloadDtos.g.cs", SourceText.From(dtoWriter.WritePayloadDtos(model), Encoding.UTF8));
        context.AddSource("AgentDraftPayloadPatchDtos.g.cs", SourceText.From(dtoWriter.WritePatchDtos(model), Encoding.UTF8));
        context.AddSource("AgentDraftChangedFieldEnums.g.cs", SourceText.From(dtoWriter.WriteChangedFieldEnums(model), Encoding.UTF8));

        // Generate projection helpers
        var projectionWriter = new AgentDraftContractProjectionWriter();
        context.AddSource("AgentDraftPayloadProjection.g.cs", SourceText.From(projectionWriter.Write(model), Encoding.UTF8));

        // Generate manifest
        var manifestWriter = new AgentDraftContractManifestWriter();
        context.AddSource("AgentDraftContractManifest.g.cs", SourceText.From(manifestWriter.Write(model), Encoding.UTF8));
    }

    private sealed record SpecClassInfo(INamedTypeSymbol Symbol, string KindName);
}
```

Add to the same file or a new file `ContractModelBuilder.cs`:

```csharp
using Microsoft.CodeAnalysis;
using System.Collections.Generic;
using System.Linq;

namespace CrestCreates.CodeGenerator.AgentDraftContractGenerator;

internal sealed class ContractModelBuilder
{
    private readonly Compilation _compilation;
    private readonly SourceProductionContext _context;

    public ContractModelBuilder(Compilation compilation, SourceProductionContext context)
    {
        _compilation = compilation;
        _context = context;
    }

    public ContractModel? Build(System.Collections.Immutable.ImmutableArray<SpecClassInfo> specs)
    {
        var kinds = new List<ContractKindSpec>();

        foreach (var spec in specs)
        {
            var kindSpec = BuildKindSpec(spec);
            if (kindSpec is not null)
                kinds.Add(kindSpec);
        }

        // Sort by DescriptorKind order for determinism
        kinds.Sort((a, b) => a.Kind.CompareTo(b.Kind));

        return new ContractModel { Kinds = kinds };
    }

    private ContractKindSpec? BuildKindSpec(SpecClassInfo spec)
    {
        if (!System.Enum.TryParse<DescriptorKind>(spec.KindName, out var kind)) return null;

        var descriptorTypeName = $"{spec.KindName}Descriptor";
        var payloadTypeName = $"{spec.KindName}DescriptorDraftPayload";

        // Resolve descriptor type from compilation
        var descriptorType = _compilation.GetTypeByMetadataName($"CrestCreates.{spec.KindName}.Abstractions.{descriptorTypeName}")
            ?? _compilation.GetTypeByMetadataName($"CrestCreates.Metadata.{spec.KindName}.Abstractions.{descriptorTypeName}")
            ?? _compilation.GetTypeByMetadataName($"CrestCreates.Event.Abstractions.{descriptorTypeName}");

        // Resolve payload type
        var payloadType = _compilation.GetTypeByMetadataName($"CrestCreates.DescriptorDraft.Abstractions.{payloadTypeName}");

        if (descriptorType is null || payloadType is null) return null;

        var fields = BuildFields(spec.Symbol, kind.ToString());

        return new ContractKindSpec
        {
            Kind = kind,
            KindName = spec.KindName,
            DescriptorType = descriptorType,
            PayloadType = payloadType,
            Fields = fields
        };
    }

    private IReadOnlyList<ContractFieldSpec> BuildFields(INamedTypeSymbol specSymbol, string kindName)
    {
        var fields = new List<ContractFieldSpec>();

        foreach (var member in specSymbol.GetMembers())
        {
            if (member is not IPropertySymbol property) continue;
            if (property.IsStatic || property.IsImplicitlyDeclared) continue;

            var attrs = property.GetAttributes();

            // Determine primary classification
            FieldClassification? classification = null;
            var fieldAttr = attrs.FirstOrDefault(a => a.AttributeClass?.Name == "AgentDraftFieldAttribute");
            var refAttr = attrs.FirstOrDefault(a => a.AttributeClass?.Name == "AgentDraftReferenceAttribute");
            var preserveAttr = attrs.FirstOrDefault(a => a.AttributeClass?.Name == "AgentDraftPreserveAttribute");
            var unsupportedAttr = attrs.FirstOrDefault(a => a.AttributeClass?.Name == "AgentDraftUnsupportedAttribute");

            if (fieldAttr is not null) classification = FieldClassification.EditableScalar;
            if (refAttr is not null)
            {
                if (classification.HasValue)
                {
                    _context.ReportDiagnostic(AgentDraftContractDiagnostics.Create(
                        AgentDraftContractDiagnostics.MultipleClassifications, property.Locations.FirstOrDefault(),
                        property.Name, kindName));
                    continue;
                }
                classification = FieldClassification.EditableReference;
            }
            if (preserveAttr is not null)
            {
                if (classification.HasValue)
                {
                    _context.ReportDiagnostic(AgentDraftContractDiagnostics.Create(
                        AgentDraftContractDiagnostics.MultipleClassifications, property.Locations.FirstOrDefault(),
                        property.Name, kindName));
                    continue;
                }
                classification = FieldClassification.Preserve;
            }
            if (unsupportedAttr is not null)
            {
                if (classification.HasValue)
                {
                    _context.ReportDiagnostic(AgentDraftContractDiagnostics.Create(
                        AgentDraftContractDiagnostics.MultipleClassifications, property.Locations.FirstOrDefault(),
                        property.Name, kindName));
                    continue;
                }
                classification = FieldClassification.Unsupported;
            }

            if (!classification.HasValue)
            {
                _context.ReportDiagnostic(AgentDraftContractDiagnostics.Create(
                    AgentDraftContractDiagnostics.NoClassification, property.Locations.FirstOrDefault(),
                    property.Name, kindName));
                continue;
            }

            // Extract modifiers
            var isRequiredOnCreate = attrs.Any(a => a.AttributeClass?.Name == "AgentDraftRequiredOnCreateAttribute");
            var contractNameAttr = attrs.FirstOrDefault(a => a.AttributeClass?.Name == "AgentDraftContractNameAttribute");
            var contractName = contractNameAttr?.NamedArguments.FirstOrDefault(kvp => kvp.Key == "Name").Value.Value?.ToString()
                ?? property.Name;

            // Extract Preserve data
            PreserveStrategy preserveStrategy = PreserveStrategy.CreateDefault;
            string? preserveReason = null;
            string? unsupportedReason = null;

            if (classification == FieldClassification.Preserve)
            {
                preserveReason = preserveAttr?.NamedArguments.FirstOrDefault(kvp => kvp.Key == "Reason").Value.Value?.ToString();
                var strategyName = preserveAttr?.NamedArguments.FirstOrDefault(kvp => kvp.Key == "CreateStrategy").Value.Value?.ToString();
                if (!string.IsNullOrEmpty(strategyName) && System.Enum.TryParse<PreserveStrategy>(strategyName, out var strategy))
                    preserveStrategy = strategy;

                if (string.IsNullOrEmpty(preserveReason))
                {
                    _context.ReportDiagnostic(AgentDraftContractDiagnostics.Create(
                        AgentDraftContractDiagnostics.MissingReason, property.Locations.FirstOrDefault(),
                        property.Name, kindName, "Preserve"));
                }
            }

            if (classification == FieldClassification.Unsupported)
            {
                unsupportedReason = unsupportedAttr?.NamedArguments.FirstOrDefault(kvp => kvp.Key == "Reason").Value.Value?.ToString();
                if (string.IsNullOrEmpty(unsupportedReason))
                {
                    _context.ReportDiagnostic(AgentDraftContractDiagnostics.Create(
                        AgentDraftContractDiagnostics.MissingReason, property.Locations.FirstOrDefault(),
                        property.Name, kindName, "Unsupported"));
                }
            }

            fields.Add(new ContractFieldSpec
            {
                PropertyName = property.Name,
                ContractName = contractName,
                Classification = classification.Value,
                PropertyType = property.Type,
                IsNullable = property.Type.NullableAnnotation == NullableAnnotation.Annotated,
                IsCollection = property.Type is INamedTypeSymbol { IsGenericType: true } nt && nt.OriginalDefinition.SpecialType != SpecialType.None
                    ? false
                    : property.Type.AllInterfaces.Any(i => i.SpecialType == SpecialType.System_Collections_Generic_IReadOnlyList_T),
                IsRequiredOnCreate = isRequiredOnCreate,
                PreserveCreateStrategy = preserveStrategy,
                PreserveReason = preserveReason,
                UnsupportedReason = unsupportedReason
            });
        }

        // Sort by classification order, then by contract name for determinism
        return fields.OrderBy(f => f.Classification).ThenBy(f => f.ContractName, System.StringComparer.Ordinal).ToList();
    }
}
```

This is the most code-intensive writer. It generates:

- [ ] **Step 1: Implement WritePayloadDtos**

Replace the entire `AgentDraftContractDtoWriter.cs` with the full implementation. The key logic:

For each kind spec, emit a `sealed record Agent{KindName}DraftPayloadDto` with:
- One property per `EditableScalar` field — map CLR type to DTO type:
  - `string` → `string?`
  - `int` → `int?`
  - `bool` → `bool?`
  - `TimeSpan?` → `string?` (ISO 8601 duration)
  - enums → the enum type itself (nullable if original is nullable)
  - `DescriptorRef` → `DescriptorRef?` (reuse from Metadata.Abstractions)

3. Reference mapping:

3. For each kind, extract existing descriptor and construct merged:

   - Fields NOT listed in ChangedFields: copy from existing
   - `Preserve` fields: always copy from existing, regardless of ChangedFields
4. Return `AgentDraftContractResult<DescriptorDraftPayload>.Success(merged)`
